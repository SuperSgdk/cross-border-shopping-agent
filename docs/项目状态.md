# 项目状态与运行限制

跨境商品随心购是 SuperSgdk 设计与开发的个人电商选购 Agent 项目，用于展示当前实现和工程设计。

## 当前范围

- 前后端源码、依赖锁文件、样例商品、知识资料、测试和部署配置随项目提供。
- 商品目录、库存和订单属于本地样例业务；未接入真实供给、支付、物流及完整账号体系。
- 模型、embedding、精排和观测服务的真实地址与凭据仅存于作者本机环境，公开配置只含占位值。
- 基础 CI 为离线回归；测试通过不等于真实模型效果或生产业务验收。
- Docker 全栈、真实模型效果和 Windows 文件 ACL 私密性尚未完成完整验收。
- Redis 等环境缺失导致的跳过不视为功能通过。
